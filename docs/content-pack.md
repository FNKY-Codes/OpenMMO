# Content Pack Layout

Third-party MMO creators ship a **content pack** — YAML game data plus asset files — separate from the OpenMMO engine. The engine loads packs via `OPENMMO_CONTENT` or an `openmmo.toml` manifest.

## Directory layout

```
my-wasteland-mmo/
├── openmmo.toml          # Pack manifest (name, engine version, paths)
├── content/              # YAML game data
│   ├── items/
│   ├── npcs/
│   ├── objects/
│   ├── recipes/
│   ├── spells/
│   ├── regions/
│   ├── quests/
│   ├── dialogues/
│   ├── shops/
│   ├── skills/
│   └── specializations/
└── assets/               # Sprites, models, audio (optional)
    ├── sprites/
    ├── models/
    ├── audio/
    ├── atlas/            # Generated by atlas-packer
    └── manifest.json     # Generated by asset-manifest
```

The reference pack in the engine repo (`content/`) is a tutorial example. Creator packs live in their own repositories.

## openmmo.toml manifest

The manifest declares pack metadata and paths. Tools and the server resolve content relative to the manifest directory.

```toml
[pack]
name = "My Wasteland MMO"
version = "0.1.0"
description = "A post-apocalyptic shard built on OpenMMO"
author = "Your Name"

[engine]
# Minimum OpenMMO engine / SDK version this pack targets
min_sdk = "0.1.0"

[paths]
content = "content"
assets = "assets"
sprites = "assets/sprites"
models = "assets/models"
audio = "assets/audio"
atlas = "assets/atlas"
```

### Field reference

| Section | Field | Required | Description |
|---------|-------|----------|-------------|
| `pack` | `name` | yes | Display name for the shard |
| `pack` | `version` | yes | Semantic version of this content pack |
| `pack` | `description` | no | Short description |
| `pack` | `author` | no | Creator or team name |
| `engine` | `min_sdk` | yes | Minimum `openmmo-sdk` version |
| `paths` | `content` | yes | Relative path to YAML content root |
| `paths` | `assets` | no | Root asset directory (default: `assets`) |
| `paths` | `sprites` | no | Sprite source images |
| `paths` | `models` | no | 3D model files (GLTF, GLB, OBJ) |
| `paths` | `audio` | no | Sound files |
| `paths` | `atlas` | no | Packed sprite atlas output |

## Running a custom pack

Point the server at your pack directory:

```bash
export OPENMMO_CONTENT=/path/to/my-wasteland-mmo/content
cargo run -p openmmo-server
```

Or place `openmmo.toml` in the pack root and run tools from that directory — they resolve paths from the manifest automatically.

## Validation workflow

Validate before starting the server:

```bash
# Cross-reference check (items, NPCs, quests, dialogues, shops, regions)
cargo run -p openmmo-content-validator -- /path/to/my-wasteland-mmo/content

# Region geometry and spawn bounds
cargo run -p openmmo-region-linter -- /path/to/my-wasteland-mmo/content

# Asset inventory
cargo run -p openmmo-asset-manifest -- /path/to/my-wasteland-mmo

# 3D model metadata
cargo run -p openmmo-model-importer -- /path/to/my-wasteland-mmo
```
